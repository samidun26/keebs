Keebs 0.1.4 runs in the menu bar without a Dock icon. Open the sound studio from the menu bar; closing it keeps keyboard sounds running in the background.

Includes 29 switch profiles, including 13 real recorded sets, plus direct sound, volume, and switch controls in the menu bar.

This release activates in-app updates for existing 0.1.2 and 0.1.3 installs. Choose **Check for Updates…** in Keebs to install it. The archive is signed with the same Ed25519 key embedded in those builds.

Development build: macOS 14 or newer, Apple silicon and Intel. No Apple Developer membership is required. The app uses ad hoc code signing; macOS may request approval to open it or grant Input Monitoring again.

Validation: macOS 14 and 26 CI passed, including native background-window lifecycle checks and packaged-app smoke checks. The published ZIP is the exact tested universal artifact; its SHA-256 and signature are verified before publication.
